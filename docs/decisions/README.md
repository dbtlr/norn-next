| [0018](0018-quarantine-cause-classes-are-closed-and-carry-the-unread-block.md) | Quarantine is per document under a closed set of four cause classes | Superseded by [0019](0019-quarantine-is-for-nothing-derivable-causes.md) | 2026-08-12 | Restates ADR 0013's boundary with a fourth cause class (a frontmatter block past the authored bound) and its true driver: findings and rows are mutually exclusive, so quarantine is the only posture that surfaces an unread block; the malformed in-bounds asymmetry is recorded as an open ruling. |
| [0019](0019-quarantine-is-for-nothing-derivable-causes.md) | Quarantine is for nothing-derivable causes, and a wholly unread block degrades to a row plus a finding | Superseded by [0020](0020-a-walk-prunes-what-its-scope-no-longer-accounts-for.md) | 2026-08-13 | A document vanishing over a YAML typo misleads more queries than a partial row carrying a reachable signal, so the findings/row exclusivity relaxes into two scopes and every wholly unread block — unclosed, malformed, past the bound — keeps its body facts beside a document-scoped finding naming the cause. |
| [0020](0020-a-walk-prunes-what-its-scope-no-longer-accounts-for.md) | A walk prunes the findings its cleanly-enumerated scope no longer accounts for | Superseded by [0023](0023-a-walk-refusal-that-stands-is-a-reading.md) | 2026-08-13 | Restates ADR 0019's boundary and degradation whole, and closes its recorded subject-axis gap: one prune rule for every walk, with authority earned by clean enumeration and withheld by refused pages, unentered roots, and opened-nothing names — never a per-place stamp. |
| [0021](0021-derived-indexes-split-into-two-lanes.md) | Derived indexes split into two lanes, and inference never re-enters correctness | Accepted | 2026-08-21 | Cross-document, nondeterministic, or version-dependent derivation cannot ride the changeset without breaking atomicity, working-set memory, and equivalence; inference able to write findings or plans would put nondeterministic claims on the surface the applier trusts. |
| [0022](0022-one-crate-knows-sql.md) | One crate knows SQL, and every database is a domain over it | Accepted | 2026-08-21 | A second database consumer would either re-grow rebuild, fingerprint, and damage machinery per engine or teach the lane-1 crate the mechanics of lanes it must not know; the store's own membership rule already named the SDK. |
| [0023](0023-a-walk-refusal-that-stands-is-a-reading.md) | A walk refusal that stands is a reading | Accepted | 2026-09-14 | Restates ADR 0020's boundary whole and splits its "a root the walk did not enter" withholder: a refusal a derivation from zero makes identically is a total statement about the places beneath it, so the walk prunes them — reaching a grammar-refused root's places by the marker they render onto — while only a vanished name or an unreadable page still withholds. |
| [0024](0024-search-enhancement-is-a-query-surface-tier.md) | The correctness boundary is findings, plans, resolution, and refusal, and search enhancement is a query-surface tier above a model-free floor | Accepted | 2026-09-20 | A ranked answer reaches none of the four protected surfaces, so pinned opt-in model rungs are admitted there under the conditions embeddings already met, with the firewall carried per rung; reading the deterministic law as barring them would protect nothing and leave the ranked tier strictly worse. |
| [0025](0025-a-reads-hold-is-demand.md) | Wire reads run on store-minted snapshot readers, a read's hold is demand, and teardown never waits for one | Accepted | 2026-09-20 | Restates ADR 0015's reader, lifetime rule and prices whole and replaces the pin's single narrow fact with the lifecycle's own demand lease: a read holds the idle interval open, withdraws an unstarted idle detach and asks for the attach or recovery the entry owes, so no idle teardown precedes a read into the entry and no read workload is a dead end, while every teardown that consults no read still moves first and a read against a parked vault refuses with the park's own code because a read withdraws no park. It also rules the reader's open a fallible mint that answers a reason rather than an absence and never panics under the entry gate. |
| [0026](0026-a-derived-store-records-the-derivation-that-wrote-it.md) | A derived store records the derivation that wrote it, and a digest of derived rows holds the record honest | Accepted | 2026-09-24 | A change to what derivation writes for unchanged input left existing stores answering differently from stores derived from zero, and no rebuild input saw it. |
