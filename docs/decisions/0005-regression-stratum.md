# 0005 — unbound regression obligations live in a registry

Regression obligations whose subjects do not yet exist live in a registry, with one case per distinct falsifiable property and all source records retained as provenance. Each case names its earliest binding venue and remains dormant until a deliberate edit names the tests carrying it. A binding is a reviewed claim that those tests carry the property; executable checks can establish that the named carriers exist, but not that the claim is semantically true.
